# Vibe Coding 一年，我被 AI 带偏的五次

> 这个项目全程用 AI 辅助开发。下面五个坑都是真实发生的，每一个都让我白干了一段时间。

## 一、AI 编了一个不存在的头文件

我问它 MNN 的 LLM 怎么接，它给我：

```cpp
#include "MNN/expr/Transformer.hpp"
auto llm = MNN::Transformer::Llm::createLLM(path);
```

命名空间对，类名对，方法名也对。唯一错的是路径——这个文件不存在，真实位置在 `transformers/llm/engine/include/llm/llm.hpp`。

这种"七分真三分假"比全编还危险。全是假的我会立刻起疑；七分真的我会直接复制粘贴，然后编译报错，再花时间怀疑是不是自己环境有问题。

**后来我加了一条规则**：任何框架 API，必须给出「文件路径 + 行号」，给不出就写「未确认」。这条规则写在 `AGENTS.md` 第一条。

## 二、编译成功，但产物是空的

让它编 MNN 的 Android 库，跑完：

```
BUILD SUCCESSFUL
-rw-r--r-- 5.7M libMNN.so
```

零错误零警告。我问了一句"这个 so 里到底有没有 LLM"，`nm` 一查——一个符号都没有。

原因是 `MNN_BUILD_LLM` 默认 `OFF`，官方脚本没传。

**我学到的是**：AI 会把"命令没报错"当成"任务完成了"。所以验收标准必须能被机器判断——不是"编译过了"，是"产物里有 59 个 `Llm::` 符号"。

## 三、停止按钮是假的

需求是流式输出 + 能中途停。它给的代码用了 `std::ostream` 接管输出，每写一个 token 就回调 Kotlin，停止标志在回调里检查。

代码读起来完全正确。但 `response()` 是阻塞的——用户点了停止，UI 不刷新了，看起来像停了，实际后台还在满负载解码。

手机上表现为发烫、掉电；更糟的是如果用户以为停了又发一条，两个 `response` 会并发跑同一个 Llm 实例，直接崩。

**这类问题的识别方式不是读代码，是问一句**："用户点下去之后，到底哪个循环退出了？"如果答不上来，就是假的。

修法是拆成 `response(..., 0)` + `while { generate(1) }`——从 MnnLlmChat 源码里翻出来的，官方文档没写。

## 四、8GB 手机被推荐了 0.5B 模型

规则写得很清楚："< 6GB 用 0.5B，6-8GB 用 1.5B"。看起来无懈可击。

拿真机一跑：

| 标称 | 实测 totalMem | 落在哪档 |
|---|---|---|
| 6GB | 5734 MB | `< 6144` → **0.5B** |
| 12GB | 11674 MB | `8-12GB` → 3B ✓ |
| 16GB | 15872 MB | `>= 12288` → 7B |

`MemoryInfo.totalMem` 不是标称容量，内核要先吃掉 0.4–0.8GB。

两个后果：6GB 手机白白降级；`>=12GB` 那一档在 12GB 手机上永远命中不了——写规则时看着合理，实际是死代码。

**规律是**：AI 写的规则在纸面上永远是对的，因为它是从"标称容量"这个概念推理的，而真实 API 返回的是另一个值。这类 bug 不报错、不崩，只是让产品在老设备上莫名变笨。唯一的发现方式是拿真实数据跑边界。

## 五、中文流式输出变成方块

`NewStringUTF` 拿到一批字节就转字符串，英文完全正常。

中文一个字 3 个字节，而 MNN 是按 token 写流的，token 边界和字符边界不重合。经常是这次来 2 个字节（一个汉字的前 2/3），下次来 1 个字节——两次都是非法 UTF-8，屏幕上两个方块。

**这个坑的本质**：AI 的代码在它想象的语言环境里是对的，它默认"每次写入是一个完整字符串"。这个假设在英文里成立，在中文里不成立。

端侧中文场景有一批这样的隐性假设：字符边界、分词、全角半角。它们不会让编译失败，只会让产品在中文用户手里显得粗糙。

---

## 五条我最后固化下来的规则

1. **让 AI 自证，不让它自信。** 每条结论标注【已核实·附路径】/【高置信推测】/【未确认】。
2. **验收标准必须机器可判。** "编译成功"不是标准，"产物里有 59 个符号"才是。
3. **不问"这段代码对吗"，问"哪个循环退出了"。** 行为层的问题在代码层看不出来。
4. **用真实数据跑边界。** 自己编的数值测不出真实世界的偏差。
5. **记录失败。** 成功案例只能证明"AI 能用"，失败案例才说明你在哪里刹住了它。

这五条没有停在博客里，全部变成了 `AGENTS.md` 的硬约束和 42 个单元测试。
