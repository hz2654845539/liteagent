# 架构决策记录（ADR）

按 Nygard 格式记录：背景 → 决策 → 理由 → 代价 → 后果。

写 ADR 的标准不是你选了什么，而是**你有没有想清楚放弃了什么**。所以每篇都有一节"放弃的方案"和"如果这个决策被推翻"。
