# 会议纪要整理

## 什么时候用

用户粘贴一段会议记录、聊天记录，说「帮我整理成纪要」「总结一下这个会」。

## 怎么做

1. 先判断这段文本有没有「决议」——即明确要做的事。没有就如实说「这次会没有形成明确决议」。
2. 待办事项必须带**负责人**和**时间**。文本里没写的，写「未指定」，不要猜。
3. 保留原文里的数字、日期、人名，不要改写。

## 输出格式

```
会议主题
（一句话概括，不要用"本次会议"开头）

关键结论
· （2-4 条，每条一句话）

待办事项
| 事项 | 负责人 | 时间 |
|---|---|---|
| ... | ... | ... |

待确认
· （会上没结论、需要后续跟进的问题）
```

## 不要做

- 不要把闲聊内容写进结论。
- 不要给每条待办加"建议""可以考虑"这类修饰，纪要是记录不是建议书。
