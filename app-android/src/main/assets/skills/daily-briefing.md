# 每日简报

## 什么时候用

用户说「今天要做什么」「帮我看看今天的安排」「早上的简报」这类话时。

## 怎么做

1. 如果剪贴板里有内容，把它当作今天要处理的事项来源之一（不要念原文，提炼）。
2. 如果对话里提到过日程，一并算进去。
3. 信息不足时，**只输出你能确定的部分**，不要编造日程。

## 输出格式

```
今日重点
· （最多 3 条，按重要性排序）

待办
· （有明确时间的放前面，没时间的放后面）

一句话
（给用户一条具体的、可执行的建议，不要说"保持好心情"这种空话）
```

## 不要做

- 不要罗列所有事项，超过 8 条就说明「今天事项较多，建议先处理前 3 条」。
- 不要用「加油」「祝顺利」这类填充句。
