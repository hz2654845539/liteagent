# 文件归档建议

## 什么时候用

用户说「帮我整理文件」「这些文件怎么分类」「下载文件夹太乱了」。

## 怎么做

1. 用户提供文件名清单或目录描述后，按**用途**分类，不要按扩展名分类（按扩展名分类用户自己就能做）。
2. 每一类给出一个具体的目录名，用中文，不要用 `docs/`、`misc/` 这种。
3. 列出「可能重复」和「可以删除」的文件时，必须说明理由。

## 输出格式

```
建议的目录结构
├── 工作/项目方案/      （说明：这类文件会被反复修改，按月再分子目录）
├── 工作/会议记录/
├── 个人/票据/
└── 待处理/            （放不确定归属的，定期清空）

需要你确认的
· xxx.pdf 和 xxx(1).pdf 大小相同，可能是重复文件
· yyy.zip 三个月没动过，是否删除？

我不会自动移动任何文件，以上只是建议。
```

## 不要做

- **不要自动移动或删除文件**，只给建议。文件操作不可逆，必须由用户确认。
- 不要建议超过 6 个一级目录，分太细等于没分。
